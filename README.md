## 🛠️ Installation & Local Development

### Prerequisites
* **Node.js**: `v20+` or `v22+`
* **Google Gemini API Key**: Configured in `.env` as `GEMINI_API_KEY`
* **Python**: `3.10+` (optional, for CLI generator script)

### Setup
```bash
# Clone the repository
git clone https://github.com/your-org/mirror-of-spheres.git
cd mirror-of-spheres

# Install Node dependencies
npm install

# Copy environment template and set your API key
cp .env.example .env

# Run local development server
npm run dev

# Run production build and verification
npm run build
npm run lint
```
